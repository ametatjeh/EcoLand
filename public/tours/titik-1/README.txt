PANDUAN PENYIMPANAN FOTO PANORAMA TITIK 1
==========================================
Lokasi: Titik 1: Gerbang Masuk & Pos Pembibitan
Koordinat GPS: 5.4813500° N, 95.5835500° E
Nama File: panorama.jpg
Path lengkap di proyek: public/tours/titik-1/panorama.jpg

CARA MENGUNGGAH DARI GO STREET VIEW (HP ANDROID):
1. Buka aplikasi Google Street View / Go Street View pada Android di lokasi Titik 1.
2. Ambil panorama 360° penuh hingga bola foto tersambung sempurna.
3. Ekspor / simpan foto dari galeri HP ke komputer.
4. Pastikan rasio aspek gambar adalah 2:1 (misalnya 4096x2048, 5376x2688, atau 8192x4096).
5. Ganti nama file menjadi `panorama.jpg` dan letakkan di folder ini:
   public/tours/titik-1/panorama.jpg
6. Halaman web Virtual Tour akan langsung memuat panorama 360° ini secara otomatis tanpa perlu mengubah kode sumber!
